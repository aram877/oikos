# Prompt: Feature Implementation

Implement [feature].

## Constraints

- No new dependencies unless explicitly justified
- Strict TypeScript — no `any`
- Minimal files — don't split unnecessarily
- Include tests for all business logic
- Explicit error handling — no silent failures
- Follow the layer structure: route → service → repository

## Deliver

1. List of files created or modified
2. Full code for each file
3. How to test it manually
4. Unit tests for the service layer
5. Edge cases covered
6. Known risks or follow-up work

## Replace `[feature]` with the specific feature, e.g.:

- "transaction split across categories"
- "monthly summary calculation"
- "recurring transaction detection"
- "CSV import with duplicate detection"
